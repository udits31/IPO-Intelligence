# Financial-information extension, frozen before scoring

The first 24-candidate bid/GMP-only search did not improve the selected model on 2025–2026. Keep that result and its selection trace. Do not promote its later-year diagnostic winner.

Add public IPO-context annual financial data, using the same HTML parser and provider for earlier and later issuers. Select only annual March-31 periods strictly before each decision; annual revenue and PAT must be numeric. Features are annual profit margin, PAT/assets, debt/net worth, signed revenue and profit growth, annual loss flag, explicitly labelled pre-offer EPS divided by announced cap, log IPO price/book and financial-sector flag. Where positive EPS and positive pre-offer P/E coexist, reject inconsistent products that differ from the offer cap by more than 5% or one rupee. Do not mix annual PAT/market-cap yields for later IPOs with EPS-based earlier valuations. Missing remains missing and uses training-only imputation. The page's statement that valuation data comes from the RHP is not independent proof of its original publication time; these results remain retrospective and publication-time-unverified.

Use two feature sets: base six inputs plus earnings yield, loss flag, revenue growth and sector; and base plus all nine new financial fields. Use the same 24 predeclared model configurations as the downside search. No new hyperparameters chosen on later-year results.

Select model, feature set and cutoff using only pooled chronological 2022/2023/2024 validation predictions. Require at least 50% negative recall on that validation cohort, addressing the specific false-positive failure. Among eligible settings, maximize accuracy, then balanced accuracy, then minimize Brier and complexity; if none qualify, select maximum balanced accuracy and report failure. Fit only 2021–2024 rows. Save the selection before scoring the exact same 155 IPOs. Report the old model, GMP-only and selected extension, all wrong calls, yearly results, paired changes, data coverage and the tradeoff in missed positive IPOs. Do not retune based on later results.
